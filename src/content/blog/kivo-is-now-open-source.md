Kivo's source code is now public on [GitHub](https://github.com/kivodev/kivo), under the AGPL-3.0 license.

Kivo is a self-hosted media server for movies, TV shows, home videos and audiobooks. You install the server on a computer or NAS that has your files, and watch or listen on your phone, TV or in a browser. There's no cloud account, no ads and no telemetry.

Kivo is still before 1.0, so expect rough edges and some changes to settings and the API between releases. If you try it, we'd like to hear how it goes, on GitHub or Discord.

To get started, see the [install guide](/docs/getting-started/).
